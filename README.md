# WealthOS

A 100% client-side wealth dashboard. No backend, no server, no database.
Data lives in your browser (localStorage). Runs on GitHub Pages.

## Dev

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy   # builds and pushes to gh-pages branch
```

App will be live at `https://<username>.github.io/wealthos/`
